1. Current SEO health

Before this pass the redesigned site could not rank. Static metadata and middleware both issued noindex, follow for www.easytravegypt.com as well as Vercel preview hosts. There was no sitemap.xml or robots.txt route. Canonical hosts disagreed (easytravegypt.com vs hathorcruise.com). Structured data existed only on Home 3 and Terms. The highest-authority Royal Suite URL transferred to Charter.

After this pass, production is indexable, preview hosts remain noindex, a keyword map is enforced in metadata, Organisation / WebSite / Breadcrumb / BoatTrip / Service / HotelRoom schema is in place, and internal links follow Homepage → Voyages → routes, plus Charter and Suites/Cabins.

Rankings will not move until Google recrawls. Submit the sitemap in Search Console and request indexing for the Royal Suite and voyage URLs.

5. Recommended fixes (this pass vs later)

Implemented now (no visual redesign)

  • Index production; keep Vercel previews noindex.
  • Rewrite titles and meta descriptions for CTR and one intent per URL.
  • Add Organisation, WebSite, Breadcrumb, BoatTrip, Service, HotelRoom, BlogPosting schema.
  • Add sitemap.xml and robots.txt.
  • Repair Royal Suite redirect; add voyage and luxury-suites aliases.
  • Internal links: homepage itineraries → /voyages; gallery suites → /suites; footer commercial column; blog CTAs mapped by topic.
  • Create /voyages/luxor-to-aswan and /voyages/aswan-to-luxor using the existing voyages editorial system.
  • Noindex Home 3, booking, admin.

Next (content, not design system)

  • P1 — Unique itinerary body on the two route URLs so they are not near-duplicates of /voyages.
  • P1 — Search Console property + sitemap submit + URL inspection for Royal Suite and both voyage routes.
  • P2 — Real FAQ blocks only where copy already answers questions, then FAQPage schema.
  • P2 — Replace remaining empty decorative alts only when the image is informative.
  • P2 — Monthly rank fill-in on the competitor tracker.
  • P3 — Retire /home-3 from the nav, then 308 it to /.
